# Local visual assets

- `orbit-courier.webp`: original AI-generated Motrix space-courier concept from the approved Orbit prototype. It is not Hatsune Miku or official MUI artwork. Converted from the original prototype PNG to a 600px WebP for local extension use. No external image request is needed.
- `dm-*.ttf`: DM Sans by Colophon Foundry and contributors, distributed under SIL Open Font License 1.1. Source: https://github.com/google/fonts/tree/main/ofl/dmsans . See `DM-Sans-OFL.txt`.
- `barlow-poster.ttf`: Barlow Condensed Black Italic by Jeremy Tribby, distributed under SIL Open Font License 1.1. Source: https://github.com/google/fonts/tree/main/ofl/barlowcondensed . See `Barlow-Condensed-OFL.txt`.
- The star/download mark is an original SVG defined in `FestivalBrand`. UI icons are from the installed `@mui/icons-material` package.
